## 🚀 Featured Projects

### 🩺 [Breast Cancer Dual-Engine Diagnostic System](https://github.com/Aarushi1512006/Breast-Cancer-ML-Explorer)
[![Live Demo](https://img.shields.io/badge/Live_Demo-Hugging_Face-yellow)](https://huggingface.co/spaces/ItsMe1501/Breast-Cancer-ML-Explorer)
[![Stars](https://img.shields.io/github/stars/Aarushi1512006/Breast-Cancer-ML-Explorer?style=social)](https://github.com/Aarushi1512006/Breast-Cancer-ML-Explorer)

**Advanced medical AI system combining CNN vision analysis with ensemble ML models**

- 🔬 Dual-engine architecture: **CNN histopathology analysis** + **7 tabular ML classifiers**
- 🎯 Consensus-based diagnosis with weighted averaging (Vision 60% | Numerical 40%)
- 📊 Trained on **BreaKHis dataset** (7,909 microscopy images) + Wisconsin Diagnostic dataset (569 samples)
- 🔧 Integrated **Tesseract OCR** for automated medical report parsing
- 📈 Real-time prediction dashboard with model comparison & confidence scores

**Tech:** TensorFlow · Keras · Scikit-learn · Streamlit · Pytesseract · Pandas
